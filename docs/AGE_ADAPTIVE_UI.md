# Age-adaptive WordPath web UI
- **Kids:** cheerful warm background, character-first presentation, larger answer controls, simple instructions, expandable adventure map, sound settings tucked away until requested.
- **Teens:** challenge/level language, purple-blue visual system and direct progress.
- **Adults:** compact, low-distraction layout with precise exercises and fewer decorative treatments.
- Shared state, lesson engine, saved progress, mastery thresholds, accessibility labels, narration provider and audio provenance remain unchanged.
- Keyboard native buttons, visible focus outlines, responsive layouts and reduced-motion style retained. All age modes remain selectable manually without collecting an age or birthdate.
- This PR is a web-first UI milestone. Mobile native still needs matching presentations and real-device usability testing. The demo has four development lessons, not a full curriculum.
